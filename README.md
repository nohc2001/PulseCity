게임 플레이 가이드 </br></br>
조작법</br>
WASD : 이동</br>
Space : 점프</br>
마우스 이동 : 방향 전환</br>
F5 : 1인칭 / 3인칭 시점 변환</br>
	- 던전에서는 1인칭이 편하다.</br>
x : 무기 내리기 / 들기</br>
c : 스탯 찍기</br>
Tab : NPC에게 말을 걸기</br>
왼쪽 클릭 : 사격</br>
오른쪽 클릭 : 정조준 (정조준이 있는 무기의 경우)</br>
Esc : 메뉴</br>
 - 메뉴로 가서 [게임 종료] 버튼을 누르면 게임이 종료됩니다.</br>
숫자버튼 123456789 : 직업을 임의로 바꿀 수 있다.</br>
EZQ : 스킬</br>
