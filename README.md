게임 플레이 가이드
조작법
WASD : 이동
Space : 점프
마우스 이동 : 방향 전환
F5 : 1인칭 / 3인칭 시점 변환
	- 던전에서는 1인칭이 편하다.
x : 무기 내리기 / 들기
c : 스탯 찍기
Tab : NPC에게 말을 걸기
왼쪽 클릭 : 사격
오른쪽 클릭 : 정조준 (정조준이 있는 무기의 경우)
Esc : 메뉴
 - 메뉴로 가서 [게임 종료] 버튼을 누르면 게임이 종료됩니다.
숫자버튼 123456789 : 직업을 임의로 바꿀 수 있다.
EZQ : 스킬

다른 존을 이동할때 잠깐 GPU 리소스 로딩 때문에 멈춤이 있을 수 있다.
좀 기다리면 존 이동이 된다.

퀘스트를 거절하면 가끔 오작동의 경우가 있어서,
만약 퀘스트 라인을 따라가지 못했을 경우, 
곧장 던전으로 가도, 던전 플레이가 가능하다.

던전방에 있는 적을 처치하면 다음 스테이지로 가는 포탈이 열리고,
보스방에서는 3개의 코어를 먼저 처치하면 보스의 방어막이 해제되며,
코어는 다시 재생된다.
보스의 채력을 모두 깎으면 게임이 클리어 되며 종료된다.
